# Roadmap

The milestones below mirror the phased plan in [`idea.md`](../idea.md). Each
milestone closes with a concrete demo and a non-negotiable verification bar.

---

## M0 — Foundation (CPU-only, eager, ~3 months)

**Goal.** A self-contained CPU training stack that can train a two-layer MLP
on MNIST to >90% training accuracy in one epoch, plus a placeholder MLIR
dialect that round-trips through `tesseract-opt`.

| ID  | Task                                                                                                                                                                                         | State   |
| --- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------- |
| T1  | Project skeleton, CMake options,`FetchContent` deps (`fmt`, `Catch2`), lint config                                                                                                     | ✅ done |
| T2  | Core types (`DType`, `Device`, `Shape`, `Allocator`, `Storage`, `Tensor`)                                                                                                        | ✅ done |
| T2t | Unit tests: creation / view / stride / contiguous / simple arithmetic                                                                                                                        | ✅ done |
| T3  | CPU kernels:`add` / `sub` / `mul` / `div` / `neg` (broadcast), `matmul`, `sum/mean/max`, `relu/sigmoid/tanh/exp/log`, `softmax/log_softmax`, `cross_entropy_with_logits` | ✅ done |
| T4  | Autograd engine:`AutogradMeta`, `Node`, per-op backward, `Engine::backward`, `NoGradGuard`, numerical-grad tests                                                                     | ✅ done |
| T5  | `nn::Module` / `Linear` / `ReLU` / `Sequential` / `CrossEntropyLoss`, `SGD`, `Adam`                                                                                            | ✅ done |
| T6  | `examples/mnist.cpp` end-to-end training + `scripts/fetch_mnist.sh`                                                                                                                      | ✅ done |
| T7  | `benchmarks/bench_matmul.cpp` vs naive baseline                                                                                                                                            | ✅ done |
| T8  | MLIR dialect skeleton (`tesseract.constant / add / matmul`) + `tesseract-opt`                                                                                                            | ✅ done |

| T9  | Docs: architecture, roadmap, ADRs (0001–0003), README quick-start                                                                                                                           | ✅ done |

**Exit criteria.** `cmake --build && ctest` green on CPU (✅ 81/81 tests
including a multi-epoch synthetic smoke test and view-op gradcheck); MNIST
MLP hits the accuracy bar (✅ 94.4 % / 96.1 % / 96.7 % test-set accuracy at
epochs 1 / 2 / 3, recorded 2026-04-18); `tesseract-opt tests/ir/roundtrip.mlir --verify-each` succeeds on any machine that finished
`build_llvm.sh` (✅ validated during T8). CPU `matmul` at 512×512 FP32 runs
at ~33 GFLOP/s with OpenMP + `-march=native` (≈ 33 × the naive triple-loop
baseline).

## M1 — Graph IR + lowering (~4 months)

**Status:** in progress. Plan + intra-milestone breakdown in
[docs/m1-plan.md](m1-plan.md); key architectural decision captured in
[ADR-0004](adr/0004-graph-ir-two-stage.md) (two-stage C++ graph ↔ MLIR).

**Goal.** Replace the eager tape with a `Graph IR` that can round-trip
training graphs, apply first-order optimizations (constant folding, CSE,
dead-code elimination, op fusion), and lower through MLIR to a CPU runner
reaching parity with the eager runtime.
